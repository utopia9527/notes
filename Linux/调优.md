# 一、缓冲区查看

- ss -t 查看所有的发送缓冲区

- 查看listen端口发送缓冲区大小

  ```shell
  ss -t -i -l '( sport = :8000 )'
  ```

- 查看系统发送缓冲区大小

  ```shell
  sysctl net.ipv4.tcp_wmem
  net.ipv4.tcp_wmem = 4096        16384   4194304
  
  最小值（4096）：TCP 发送缓冲区的最小值。
  默认值（16384）：系统自动调整时的默认大小。
  最大值（4194304）：发送缓冲区的最大大小。
  ```

- 查看端口流量

  ```shell
  netstat -atpn | grep 8000
  
  第一个是接收缓冲区、第二个是发送缓冲区
  tcp        0      0 xxx:47188      xxx:8000       ESTABLISHED 20336/python
  tcp        0    298 xx:47216      xxx:8000       ESTABLISHED 20336/python
  ```
