  - Linux 中的内存（cache，buffer，swap）

  - 在Linux系统中，为了提高文件系统性能，内核利用一部分物理内存分配出缓冲区，用于缓存系统操作和数据文件，当内核收到读写的请求时，内核先去缓存区找是否有请求的数据，有就直接返回，如果没有则通过驱动程序直接操作磁盘。
  
- 内存查看命令

- free -h
  - [内存free和available区别](https://blog.csdn.net/qq_36249352/article/details/127319060)
    - 真正可用的内存 =  avaliable + cache + buffer (大概计算方法)
    - inux 为了提升读写性能，会消耗一部分内存资源缓存磁盘数据，对于内核来说，buffer 和 cache 其实都属于已经被使用的内存。但当应用程序申请内存时，如果 free 内存不够，内核就会回收 buffer 和 cache 的内存来满足应用程序的请求
    - cache(缓存)： 文件系统层级的缓存,从磁盘里读取的内容是存储到这里.比如grep 第一次很慢，第二次就快了
    - buffer(缓冲)：程序将内容写入磁盘，并不是一次性写入，而是先写入到cache 之中

    - 内存占用提取脚本
  
      ```bash
      #!/bin/bash
      PID=23622  # 替换为你的进程PID
      INTERVAL=2  # 间隔秒数
      OUTPUT=memory_log.txt  # 输出日志文件
      
      # 写入表头（固定宽度，用空格分隔）
      printf "%-20s %6s %10s %10s %10s %10s %10s %10s\n" \
          "时间" "%MEM" "RSS(KB)" "RSS(MB)" "RSS(GB)" "VSZ(KB)" "VSZ(MB)" "VSZ(GB)" > $OUTPUT
      
      # 循环采集
      while true; do
          # 提取原始指标（%MEM、RSS、VSZ）
          stats=$(ps -p $PID -o %mem,rss,vsize --no-headers)
          if [ -z "$stats" ]; then
              echo "进程已结束，停止监控"
              exit 0
          fi
      
          # 解析字段
          mem_percent=$(echo $stats | awk '{print $1}')
          rss_kb=$(echo $stats | awk '{print $2}')
          vsz_kb=$(echo $stats | awk '{print $3}')
      
          # 转换单位（保留两位小数）
          rss_mb=$(echo "scale=2; $rss_kb / 1024" | bc)
          rss_gb=$(echo "scale=2; $rss_mb / 1024" | bc)
          vsz_mb=$(echo "scale=2; $vsz_kb / 1024" | bc)
          vsz_gb=$(echo "scale=2; $vsz_mb / 1024" | bc)
      
          # 固定宽度输出（-表示左对齐，数字表示宽度）
          printf "%-20s %6s %10s %10s %10s %10s %10s %10s\n" \
              "$(date +"%Y-%m-%d %H:%M:%S")" \
              "$mem_percent" \
              "$rss_kb" \
              "$rss_mb" \
              "$rss_gb" \
              "$vsz_kb" \
              "$vsz_mb" \
              "$vsz_gb" >> $OUTPUT
      
          sleep $INTERVAL
      done
      ```
