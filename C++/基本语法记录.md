# 一、拷贝构造那些事

- 默认拷贝构造会调用子成员自己的拷贝构造。 有拷贝构造则不会去主动调用子成员拷贝构造函数

```c++
class MyClass {
 public:
  std::mutex mtx;
  // 其他成员函数
  MyClass() { std::cout << "普通构造" << std::endl; }

  MyClass(MyClass& m) { std::cout << "不拷贝锁" << std::endl; }
};

int main() {
  // 调用构造函数
  auto p3 = std::make_unique<MyClass>();
  // 调用拷贝构造
  auto p4 = std::make_unique<MyClass>(*p3);
}

```
