class CoordConvertTest : public testing::Test {
 protected:
  std::string r = "beijing_yizhuang";
  hdmap::map_route_planner::CoordConver coord_conver(r);
};


1. 类的定义和继承
class CoordConvertTest : public testing::Test
这段代码定义了一个测试类 CoordConvertTest，它继承自 Google Test 框架提供的基类 testing::Test。通过继承：

测试类的功能：你可以利用 SetUp、TearDown 等机制，在每个测试用例运行之前或之后执行特定的初始化和清理工作。
组织测试用例：测试类中的所有测试用例共享这段代码的上下文（protected 成员和设置逻辑）。
  
  
2. protected 成员变量
std::string r = "beijing_yizhuang";
hdmap::map_route_planner::CoordConver coord_conver(r);
成员变量的定义
std::string r = "beijing_yizhuang";

定义了一个字符串变量 r，表示一个区域标识（region），例如 "beijing_yizhuang"。这是构造 CoordConver 所需的参数之一。
hdmap::map_route_planner::CoordConver coord_conver(r);
定义并初始化了一个 hdmap::map_route_planner::CoordConver 类型的对象 coord_conver，并将 r 作为构造函数的参数。

  
3.为什么定义成protected变量
在 Google Test 中，TEST_F 宏定义的每个测试用例实际上会创建一个测试类（如 CoordConvertTest）的实例。如果你需要在测试类的基础上扩展更多功能（比如定义新的派生测试类），protected 可以让派生类直接复用这些成员变量，而无需额外暴露给外部。如果成员是 private 的，派生类将无法访问它们，这会限制测试用例的灵活性。
